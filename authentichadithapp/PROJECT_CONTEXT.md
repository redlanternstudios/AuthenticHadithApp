# Project Context

## Project Name

Authentic Hadith

## Project Type

iOS-first cross-platform mobile app built with Expo, React Native, TypeScript, Supabase, RevenueCat, and AI features.

The app may also target Android and web based on available package scripts, but the current priority is iOS launch readiness.

The goal of Authentic Hadith is to provide a trustworthy Islamic mobile app experience centered on authentic hadith access, study, and user engagement.

The app should prioritize:

1. Authenticity.
2. Reliability.
3. Clean user experience.
4. Respectful Islamic presentation.
5. Stable iOS launch readiness.
6. Safe handling of subscriptions/payments.
7. Clear App Store/TestFlight release discipline.

The current objective is to move the app toward a stable iOS launch pipeline.

Primary focus areas:

1. Maintain a clean Expo / React Native build.
