## 2. Restricted Behaviors

- No cloning of unindexed public repositories into this workspace.
- No copy-paste of arbitrary agent frameworks, boilerplate starters, or AI orchestration libraries without explicit approval.
- `git push --force` to `main` is locked. `git push --force-with-lease` to feature branches is allowed.
- `git reset --hard origin/main` requires explicit confirmation.
- `npx expo prebuild --clean` is destructive (per root CLAUDE.md) and requires KP approval.
- `rm -rf node_modules`, `rm -rf ios`, `rm -rf android` require KP approval.
- No skipping pre-commit hooks (`--no-verify`) or signing (`--no-gpg-sign`).

## 3. Escalation Protocol

When a requested operation crosses any of the above:

1. HALT loop execution immediately.
2. State which rule is triggered.
3. Present a line-by-line diff of the proposed change.
4. Wait for explicit human approval before proceeding.
5. Log the escalation to `BUILD_FIX_LOG.md` whether approved or denied.
