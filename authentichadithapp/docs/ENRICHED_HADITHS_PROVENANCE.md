# enriched_hadiths Provenance

**Status:** UNRESOLVED — App Store submission blocker for the Key Teaching panel.

## What this table is

The Supabase table `enriched_hadiths` is referenced from the mobile hadith
detail screen at `app/hadith/[id].tsx`. The two columns the app reads are:

- `key_teaching_en` — a short English "key teaching" string, rendered on the
  detail screen in a styled gold-accent panel labeled "Key Teaching".
- `summary_line` — a one-line summary (not currently rendered on mobile).

The table is **not documented** in `V1_SCHEMA_ALIGNMENT_AUDIT.md`. It was added
to production outside the documented V1 schema sprint.

## Why this matters

The Key Teaching panel is rendered without any author attribution or label.
Visually it looks like scholarly commentary. If the rows in `enriched_hadiths`
were generated by an AI model (rather than reviewed/written by a qualified
scholar), the app would be presenting AI religious commentary as authoritative
teaching — which violates the content-trust posture the app commits to in
`APPSTORE_METADATA.md` ("AI assistant is trained to provide context, not fatwa")
and in onboarding.

## Current mitigation

`app/hadith/[id].tsx` defines `ENRICHED_HADITHS_ENABLED = false` and gates the
React Query for `enriched_hadiths` behind that flag. The panel is hidden until
this doc is filled in.

## What we need before re-enabling

Pick one of the two paths and fill in the answers:

### Path A — Scholar-reviewed content

- Who wrote/reviewed the rows? (name, scholarly credentials)
- What source materials did they consult?
- What license applies to the text?
- Is the dataset complete, or partial? If partial, which hadith IDs are covered?

**Action when this path applies:** flip `ENRICHED_HADITHS_ENABLED = true` and
add an inline credit line on the panel: "Reviewed by &lt;name&gt;,
&lt;credential&gt;."

### Path B — AI-generated content

- Which model generated the rows?
- What system prompt was used?
- Has any sample been reviewed by a scholar for accuracy?
- Will rows be re-generated or curated going forward?

**Action when this path applies:** flip `ENRICHED_HADITHS_ENABLED = true` and
rename the panel header from "Key Teaching" to "AI-generated insight". Append
the standard footnote: "AI-generated. Not a religious ruling." Match the AI
Summary styling so users can distinguish AI text from primary hadith text.
