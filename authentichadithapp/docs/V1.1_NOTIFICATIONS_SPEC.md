# v1.1 Engagement Notifications — Scoped Spec (PARKED until v1.0 ships)

**Status:** APPROVED SCOPE, NOT STARTED. Hard rule: must not block v1.0 App Store submission. No code, no dependency installs, no config changes until KP authorizes the v1.1 sprint.

## Objective
Opt-in educational reminders (Duolingo/Coursera-style, adapted respectfully for AuthenticHadith) to lift retention and learning consistency.

## Notification types (all opt-in, individually toggleable)
| # | Type | Trigger | Example copy |
|---|---|---|---|
| 1 | Daily Hadith Reminder | user-selected time | "Your daily hadith is ready." |
| 2 | Continue Learning | lesson/module started but unfinished | "Continue where you left off." |
| 3 | Streak Reminder | app not opened by selected time | "Keep your learning streak alive." |
| 4 | Weekly Progress | weekly summary | "You completed 4 lessons this week." |
| 5 | Friday Reflection | optional Jumu'ah reminder | "Take a moment for reflection this Friday." |
| 6 | Re-engagement | inactivity 3/7/14 days | "Your learning path is waiting." |

## Hard requirements
- Opt-in only; clear iOS permission request flow; per-type on/off toggles; reminder-time picker.
- No spam (rate caps; re-engagement stops after the 14-day touch until user returns).
- Quiet, respectful wording — no intrusive religious claims in push copy.
- No crash when permission is denied (degrade silently, toggles reflect denied state with a Settings deep-link).
- Tested on physical iPhone before ship.
- App Review notes must explain notification use.

## Technical investigation (done, read-only — 2026-06-12)
- **`expo-notifications` is NOT installed** (verified package.json) → v1.1 needs `npx expo install expo-notifications expo-device` (KP-gated install, new build required).
- **Local scheduled notifications FIRST** — types 1, 3, 5 are pure local schedules (no server). Type 2/4/6 can also be computed locally from `progressService` (`active_days`, completion records already exist) and (re)scheduled on app open. **No APNs / remote push needed for the entire v1 of this feature.**
- Remote push (APNs keys, EAS credentials, Supabase-stored preferences) only if later personalization demands it — defer.
- The v1.0 Notifications settings screen (FIX-081 clean state) is the natural home for the toggles + time picker.
- Permission flow: request only on first toggle-ON (not at launch), per HIG.

## Definition of Done (v1.1)
- Enable/disable daily reminder; choose time; notification fires at chosen time; tapping opens app (deep-link to Today); disable works; permission-denied path crash-free; review notes updated.
